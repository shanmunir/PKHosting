# PKHosting VPS Hosting (static demo)

Open `index.html` in a modern browser (Chrome/Firefox). This is a self-contained static demo; no server required.

Browsers tested: Chrome  (desktop/mobile widths), Firefox.

How to open:

1. Double-click `index.html` or open it from your browser via File → Open.
2. The demo is fully offline; currency and billing period persist via `localStorage`.

What is unfinished: this is a static demo—no checkout flow, no backend.
